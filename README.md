# WuWa Clone — 명조(Wuthering Waves) 스타일 오픈월드 액션 데모 v4

Unity 6 (6000.5) + URP 기반, **Unity CLI로 빌드된** 오픈월드 액션 RPG 데모입니다.
명조의 핵심 전투(포르테 회로·협주·변주/여운·패리·회피 반격)와 트래버설(벽타기·갈고리·활공·수영·스태미나),
8지역 오픈월드·개체별 스탯 에코·무기·퀘스트 3장·세이브·워프·보물상자·NPC/상점·시련 아레나·침식 균열 이벤트까지 재현했습니다.

## 서드파티 에셋 (저장소 미포함)

Asset Store EULA상 재배포할 수 없는 팩은 저장소에서 제외했습니다. **플레이만 할 거라면 Releases의 설치기로 충분**하고(빌드에 전부 포함), 에디터에서 열려면 아래 팩을 Asset Store에서 받아 **같은 폴더 이름**으로 임포트한 뒤 애니메이션을 재생성해야 합니다.

임포트 후 재생성 순서(Unity CLI eval 또는 메뉴):
1. `WuWa.EditorTools.WuWaAnimBuild.BuildAll()` → `AddWuWaStates()` (팩 클립을 `Assets/WuWa/Anim/Clips/*.anim`으로 복제하고 Member/Enemy 컨트롤러 생성; 이 복제본도 팩 라이선스를 따르므로 저장소에서 제외됨, `Fist.anim`만 자체 생성)
2. `WuWaCharBuild.BuildMemberPrefabs()` (AttackDef의 clipLen 베이크)
3. 월드가 비어 있으면 `WuWaWorldBuild.BuildGameAll()` → `WuWaWorldExpand.BuildWorldAll()` → `WuWaQualityPass.ApplyStep1/2/3()`

## 실행 방법
- **설치 마법사 (권장)**: [GitHub Releases](https://github.com/gitUserKHS/wuwa_clone/releases/latest)에서 `WuWaClone-<버전>-Setup.exe`를 받아 실행 (한국어/영어, 관리자 권한 불필요, 제어판에서 제거 가능). 설치기는 `Tools/installer.iss`(Inno Setup 6)로 만들며, 빌드 순서는 아래 "빌드 · 릴리스" 참고.
- 스탠드얼론(직접 빌드): `WuWa.EditorTools.WuWaPlayerBuild.BuildWindows(outDir, version)` 결과 폴더의 `wuwa_clone.exe` (부트 로딩 화면 → 자동 이어하기)
- Unity 에디터: `Assets/WuWa/Scenes/WuWaField.unity` 열고 Play

## v4 — 품질 패스
### 그래픽
- **잎/풀 컷아웃 셰이더** `WuWa/ToonFoliage`: 폴리토프 잎 카드가 검게 뭉개지던 문제 해결(알파 컷아웃·양면·바람·투과광·잎 모양 그림자·SSAO 노멀 패스).
- **포스트 프로세싱** 실제 적용: 블룸·Neutral 톤매핑·색 보정·스플릿 토닝·비네트·렌즈 플레어 (기존 프로파일은 비어 있었음).
- **GPU 풀밭** `GrassField`: 20m 청크별 프로시저럴 잎 ~1,500개를 StructuredBuffer + `RenderMeshPrimitives`로 인스턴싱, 지형 페인트 색을 그대로 물려받아 지역마다 색이 다름(서리 고원=흰 풀, 황무지=마른 풀), 도로·급경사·물가 자동 제외, 바람·플레이어 밀림, 시간분할 빌드.
- **지형 셰이더 디테일**: 월드 노이즈 매크로/마이크로 변화, 급경사 지층 띠, 눈밭 반짝임, 구름 그림자(라이트 쿠키) 수신.
- **낮/밤 주기** `DayNightCycle`(22분/일): 태양·달 궤도, 하늘 팔레트 9키(새벽·정오·노을·밤), 별·달, 안개/앰비언트 전환, **스크롤 구름 그림자 쿠키**, 밤에 마을 등불 점등·반딧불, `_WuWaNight` 전역으로 커스텀 셰이더 음영 심화. HUD 시계(미니맵 아래), 세이브에 시각 저장.
- **물**: 깊이 기반 해안 거품/부드러운 교차, 태양 글린트, 프레넬 하늘 반사, 원거리 물결선 페이드.
- **야생**: 나비 26마리(낮, 초원/숲/언덕/마을/호수)·새 7마리 편대 비행(정점 플랩 셰이더), 밤 반딧불.

### 게임플레이 (감사 기반 수정)
- **완벽 회피가 진짜 타이밍 판정**: 무적 프레임이 회피 전체가 아닌 앞 60%(0.02–0.26s)이며, 회피 시작 0.2s 이내에 맞아야 완벽 회피(슬로모+반격 창).
- **선입력 버퍼**: 스윙 도중 누른 공격이 캔슬 창에서 자동 이어짐(0.5s 유효).
- 콤보 4타 **피니셔**(캔슬 불가 구간 확대 + 흔들림/FOV 펀치), 슬래시 VFX/피치 인덱스 오프바이원 수정.
- **보스 2페이즈**(HP 50%): 공속·이속 상승, 슬램 확률 상승, 질풍 그림자 2체 소환, 포효 연출.
- 락온 Tab 순환 · 락온 중 상하 시점 유지 · FOV 펀치 시간 인자 반영 · 히트스톱이 열린 메뉴를 풀지 않음.
- 정예 그림자(붉은 발광·슈퍼아머·1.7× 체력)와 `EnemyRegistry` 런타임 스폰 API.

### 컨텐츠
- **NPC & 대화**: 메아리 마을 상인 마르타·아이 피오, 제단지기 로엔 — 타자기 대화창(F/Space/클릭), 진행도에 따라 대사 변화.

## S1 — 입력·설정 기반 (시스템 설계서 12장 로드맵 1단계)
- **액션 에셋** `Assets/WuWa/Resources/Input/WuWaInput.inputactions`: `WuWaInputSpec`의 C# 테이블에서 결정적 GUID로 생성(메뉴 `WuWa/Input/Generate Action Asset`). 맵 7종(Player/System/UI/Menu/Map/Dialogue), 키마 + 게임패드 기본 배치는 명조 준거 — 패드 RB 회피(홀드 = 질주) · Y 스킬 · B 상호작용 · LB 에코 · X 공격 · A 점프 · RT 해방 · D-pad ↑→↓ 교대 · R3 락온(홀드 = 해제, 대상 없으면 카메라 리센터) · View 지도 · Menu 일시정지.
- **InputService**: 컨텍스트 스택(Gameplay/Menu/Map/Dialogue/Cutscene/Rebind)으로 맵을 켜고 끄며, 프레임 스냅샷(`JumpPressed`…)을 모든 스크립트가 읽는다. 전투 액션에 Tap/Hold 인터랙션 없음(0프레임 지연). 활성 장치 감지(히스테리시스) → 글리프(`Glyph.Prompt`, "F"/"Ⓑ"/"○") · 커서 규칙(`CursorService`) · 진동(`HapticsService`) 자동 전환. 13개 스크립트의 `Keyboard.current` 직접 폴링 제거. `InputSim`은 가상 장치로 실제 액션 경로를 테스트.
- **설정 저장소** `options.json`(세이브와 분리, 기존 세이브 옵션 1회 이관): `SettingsCatalog`에 등록된 62개 항목이 옵션 화면(탭 6개 · 스크롤 · 슬라이더/토글/사이클/홀드 버튼)으로 자동 생성되고 즉시 적용 — 창 모드/해상도/수직동기/프레임 상한/품질 프리셋/렌더 스케일/그림자/AA/SSAO/블룸/비네트/플레어/풀 밀도·거리/장식 거리/밝기/시야각/FPS, 볼륨 3종, 마우스·패드 감도 X/Y·가속·반전·데드존·응답 곡선·트리거 임계값·진동 4종, 질주 방식·자동 질주·우클릭 회피·락온 카메라 추적/보정·이동 카메라 정렬·카메라 거리 2종·글리프 스타일·조작 초기화, 흔들림·히트스톱·슬로모·섬광·대미지 숫자 3종·미니맵 범위·트래커·대화 속도/자동·자동 저장 알림·HUD 크기, 색각 보정(예고색 팔레트)·섬광 줄이기·홀드→토글·타이밍 보조(완벽 회피/무적/예고/버퍼 창)·자막 크기, 저장/주기/초기화/삭제(2초 홀드)/폴더.
- **카메라**: 감도·반전·FOV·기본/전투 거리·락온 보정 강도·자동 정렬을 설정에서, 휠·R3+우스틱 줌은 스무딩(노치당 ×1.12)되어 저장. 메뉴/지도/대화/컷씬 중 카메라가 도는 버그 수정.
- ESC = 설정 허브(S2에서 일시정지 메뉴로 교체), Alt 홀드 = 커서 해제, F11 = HUD 숨김. 검증: 가상 게임패드/키보드/마우스로 점프·공격·회피·교대·이동·지도·일시정지·대화→상점·Alt·줌·설정 왕복/초기화 모두 통과(콘솔 에러 0).

## S2 — UI 프레임워크 + 일시정지 · 설정 · 리바인딩 (로드맵 2단계)

## 검 그립 · 자세 (2026-09-04)

유니티짱 교체 뒤 검이 **손바닥 법선 방향으로 뚫고 나가고**(Meshy 리그에 맞춘 고정 오프셋 `Euler(0,90,-90)`), 손은 펴진 채였으며, idle은 이름이 가장 짧은 "Idle"이 뽑히는 휴리스틱 탓에 **Brute@Idle**(거한 전사의 벌린 자세)이었습니다. 세 층으로 교정했습니다.

- **그립 축을 손가락 본 기하로 계산** — `WeaponVisual.GripPose()`. 손목→중지 너클 = f, 새끼→검지 너클 라인(f 성분 제거) = across = **칼날 방향**, 둘의 외적 = 손바닥 법선(엄지 근위 본이 있는 쪽으로 부호 결정). 검 +Y=across, +Z=법선(`LookRotation(n, across)`). 근위 손가락 본은 손 본의 **직계 자식**이라 손 기준 위치가 애니메이션과 무관하게 상수 → 어떤 휴머노이드 리그에도 그대로 붙고, 손가락 본이 없으면 구 오프셋으로 폴백합니다. 위치는 손목에서 손가락 방향 `gripAlongFingers` 0.092 m + 손바닥 쪽 `gripPalmOffset` 0.024 m이고, `BuildSword`의 그립 실린더 중심(y=0.02)이 주먹 중심에 오도록 보정합니다. (유니티짱 오른손: 손가락 −X, 너클 라인 +Y, 손바닥 −Z.)
- **핸드셰이크 그립 트림** `gripTrimEuler = (0, 0, −32°)`(검 자체 Z = 손바닥 법선 둘레): 손잡이를 손바닥에 **대각선**으로 두면 칼날이 팔뚝의 연장선이 됩니다. 해머 그립(0°)이면 팔을 내린 휴식 idle에서 칼날이 **수평 정면(창처럼)** 으로 나갑니다. −32°에서 휴식 시 전방 아래 24°, 가드 시 팔 연장선, 달리기 시 엉덩이 옆 전방(칼끝 높이 0.7~0.9 m, 다리·지면 간섭 없음).
- **오른손 주먹 레이어** — `WuWa.EditorTools.WuWaAnimBuild.ApplySwordPose()`(메뉴 `WuWa/Anim/Apply sword pose`, `BuildAll` 끝에서도 자동 호출, 멱등). 팩의 클립은 전부 비무장이라 **오른손 손가락 머슬 커브 15개**가 손을 펴 버립니다 → `Anim/Clips/Fist.anim`(오른손 머슬 커브 20개, 상수) + `Anim/RightFingers.mask`(RightFingers만 활성) + 각 Member 컨트롤러에 `Grip` **오버라이드 레이어**(weight 1). 머슬 값은 ±1(아바타 한계) 밖으로 **외삽**되므로 −1.3/−1.7/−0.8(너클/중간/끝)이 실측 굽힘 104°/113°의 주먹이 됩니다(`FistMuscles`에서 조정).
- **idle 교체** — Loco 블렌드트리를 `FreeformCartesian2D`(X=Speed, Y=**Combat**)로 재작성: `MemberIdle`(KI `HumanF@Idle01`, 휴식 자세) ↔ `MemberIdleCombat`(KI `HumanF@CombatIdle1H01`, 한손검 가드). `PlayerController`가 `Combat` 파라미터를 `InCombat`(적 15 m 내 어그로)으로 0.2 s 댐핑 구동합니다. 기존 `"Loco"` 크로스페이드 코드는 그대로 동작하고, 적 컨트롤러의 Brute idle은 건드리지 않았습니다. `CombatPoseOverride`/`SpeedPoseOverride`(정적, −1=미사용)는 캡처·프리뷰용 강제값입니다.
- **검증** — `WuWaPlaytest.Run(dir)`가 멤버마다 휴식 / 가드 / A1 와인드업 / 달리기 2프레임의 전신과 손 근접(`_hand_out` 팔 바깥, `_hand_back` 손등, `_hand_oblique`, `_hand_wide`)을 찍고, report에 검 로컬 TRS · 손가락 굽힘각 · 칼날 방향(전/상/우 성분) · 칼끝 높이를 남깁니다. 결과는 `Screenshots/swordpose/`. 함정: `EditorApplication.update` 틱은 게임 프레임보다 2~3배 잦아 "55틱 뒤"가 0.15 s밖에 안 됩니다(A1 캡처가 정규화 시간 0.13에 잡힘). `hand_palm`(손바닥 법선 쪽 카메라)은 손바닥이 몸을 향해 몸 안에서 찍히므로 손등 쪽으로 바꿨습니다.
- **튜닝 손잡이**: 칼날 기울기 `WeaponVisual.gripTrimEuler.z`, 손 안 위치 `gripAlongFingers`/`gripPalmOffset`, 주먹 세기 `WuWaAnimBuild.FistMuscles`(바꾼 뒤 `ApplySwordPose()` 재실행), idle 클립 `MemberIdleNames`/`MemberCombatIdleNames`.
